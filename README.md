## Comandos executados
 whoami: mostra o utilizador atual.
 hostname: mostra o nome da máquina.
 uname -a: apresenta informações do sistema Linux.
 pwd: mostra o diretório atual.
 mkdir -p: cria diretórios.
 tree: mostra a estrutura de diretórios.

## Diferença entre VM, VPS e infraestrutura em nuvem
 VM: máquina virtual executada localmente no computador.
 VPS: servidor virtual alojado remotamente.
 Infraestrutura em nuvem  recursos disponibilizados através da Internet.
